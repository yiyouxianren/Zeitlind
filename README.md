## 主要功能

- 推荐视频 / 热门 / 排行榜 / 直播 / 番剧
- 视频播放（弹幕、字幕、倍速、画质/解码选择、手势控制）
- **离线缓存**：视频下载（含弹幕/分段信息）、后台批量下载、断点续传、导入外部文件
- 批量取关、批量移除收藏
- 动态、评论、私信、搜索、稍后再看、观看记录、我的收藏
- 极简模式（首页仅收藏夹）
